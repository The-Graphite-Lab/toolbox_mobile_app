A — Centered Column

Keep the phone layout in a centered max-width column (~420px). Simple, no layout changes needed. Content stays familiar but uses iPad space for breathing room.

Pros

  • Minimal code changes
  • Phone layout stays intact
  • Consistent experience

Cons

  • Wastes iPad screen real estate
  • Feels like a phone app on iPad

B — Scale + Breathe

Keep single-column layout but scale everything up: bigger text, more padding, larger cards, wider touch targets. The whole UI uses the iPad space without rearranging anything. Like the phone layout "grew up."

Pros

  • Uses full iPad width naturally
  • Bigger touch targets for field use
  • Feels intentional, not cramped

Cons

  • Cards may look oddly wide
  • Single-column list with 3 items looks sparse

C — Adaptive Grid

Scale up text/spacing AND rearrange cards into a 2-column grid on iPad. Best of both worlds — bigger UI elements plus smarter use of horizontal space. Active view stays single-column and centered.

Pros

  • Best use of iPad screen real estate
  • Feels like a native iPad app
  • Scales up AND rearranges

Cons

  • More CSS changes needed
  • Need to handle odd card counts
