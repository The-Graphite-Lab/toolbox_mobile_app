# BUG_1 Instance - 2026-02-27T01-18-44Z

## Description
- iOS runtime continued to report `"AudioRecording" plugin not implemented` after prior file-reference fixes.

## Symptoms Observed
- Capacitor bridge JS error indicates plugin lookup failed by plugin name (`AudioRecording`).
- `npx cap sync ios` output only detected one iOS plugin (`@capacitor/app`), not the custom local plugin.
- Generated `ios/App/App/capacitor.config.json` `packageClassList` did not include `AudioRecordingPlugin`.

## Troubleshooting Steps
1. Re-validated plugin files and bridge macro definitions.
   - Result: `AudioRecording.m` and `AudioRecording.swift` implementation looked correct.
2. Investigated Capacitor iOS plugin loading path.
   - Result: Bridge autoloads classes from `capacitor.config.json` `packageClassList`.
3. Confirmed custom local plugin was not in auto-generated class list.
   - Result: Runtime registration gap remained possible even with correct compilation.
4. Implemented explicit runtime registration:
   - Added `BridgeViewController` subclass of `CAPBridgeViewController`.
   - Registered plugin in `capacitorDidLoad()` via `bridge?.registerPluginInstance(AudioRecordingPlugin())`.
   - Updated `Main.storyboard` initial view controller class to `BridgeViewController`.
   - Added new Swift file to Xcode project build phases.
5. Rebuilt and re-synced:
   - Result: `xcodebuild` simulator builds succeeded pre/post sync.

## Resolution Summary
- Root issue in this instance was missing explicit bridge registration for a local in-app Capacitor plugin.
- Fix applied by moving plugin registration into custom bridge controller lifecycle.
- This makes runtime plugin availability independent of the auto-generated `packageClassList`.

## Lessons Learned
- For local iOS plugins not managed as npm Capacitor plugins, rely on explicit registration in a custom `CAPBridgeViewController` subclass.
- `cap sync ios` can regenerate `capacitor.config.json` and omit local plugin class names, so runtime registration should not depend on that file alone.
